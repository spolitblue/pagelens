PageLens 帮助 常见问题

为什么有些页面用不了，以及截图去哪了。

为什么浏览器内置页面没有 PageLens 气泡？

Chrome / Edge 不允许任何扩展往这些页面注入脚本或截图：chrome://、edge://、about:、扩展商店（Chrome Web Store / Edge Add-ons）、浏览器的 PDF 阅读器，以及部分受保护的企业页面。

正常现象 换成普通网站（http/https）刷新后，右下角就会出现气泡。

按了扩展图标却没反应？

  • 页面可能是在安装扩展之前打开的：刷新页面即可。
  • 可能落在上面的受限页面里，看下一节。
  • 如果页面上出现了黄色提示条，说明当前标签页不允许扩展注入。

截图包括哪些内容？

默认截取你当前看到的浏览器可视区域（不是整页长截图），并且会先把 PageLens 自己的面板隐藏掉，所以截图里没有对话框。你也可以点剪刀图标，只框选一块区域；框选的坐标会映射到真实截图分辨率，高 DPI 屏幕也没问题。

为什么回答里说“看不到图片”？

检查设置里的模型是否为 deepseek-flash。当前 DeepSeek 目录里的 deepseek-v4-pro 只支持文本输入；看图问答必须使用带视觉能力的模型。另外，如果截图区域太小或纯色，模型也可能没有足够信息。

桥接连不上怎么办？

  1. 在项目文件夹双击 bridge/start-bridge.bat，确认命令行窗口里出现“监听 http://127.0.0.1:8790”。
  2. 保持那个窗口开着（关掉窗口桥接就停了）。
  3. 回到设置，点「自动配对」，再点「测试连接」。
  4. 如果仍然失败，确认本机 ~/.dsh/.credentials.yaml 里有 DEEPSEEK_API_KEY；或者切到「直连 API」填 Key。

桥接只监听 127.0.0.1，并且用随机令牌鉴权。API Key 只存在于桥接进程读取的环境/文件里，不会传进浏览器扩展，也不会被网页拿到。

PageLens 会保存我的对话吗？

不会。对话、截图和页面文字只保存在当前标签页的内存里，刷新或关闭页面就会消失。设置（模型、主题、桥接令牌/API Key）保存在浏览器的 chrome.storage.local。只有点击发送时，数据才会发给你配置的 API。

快捷键

Alt+Shift+L 打开/收起面板；Alt+Shift+S 框选区域。若被其他软件占用，可在 chrome://extensions/shortcuts 里改。

数据和隐私

页面文字只取可见区域的 innerText，最多约 6500 字，不读取输入框的值。截图与页面文字会发送到你设置的 DeepSeek API；请避免对含有密码、身份证等敏感信息的页面提问。你随时可以在面板里关掉「附带页面文字」，只发送截图。
